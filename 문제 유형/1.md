# SQLP 문제 접근 방법 정리

## 문제 핵심

테이블의 PK 인덱스 컬럼 순서는 다음과 같다.

```sql
상품번호, 변경일시, 변경구분코드
```

즉 인덱스는 다음 순서로 정렬되어 있다고 볼 수 있다.

1. 상품번호
2. 변경일시
3. 변경구분코드

따라서 어떤 조건이 인덱스를 잘 활용하는지 판단하는 것이 핵심이다.

---

# 문제를 볼 때 생각해야 할 포인트

## 1. 최근 1년 조건

문제에서는 최근 1년 내 데이터만 조회한다.

```sql
변경일시 >= TRUNC(ADD_MONTHS(SYSDATE, -12))
```

이 조건은 변경일시에 대한 범위 조건이다.

즉 인덱스에서 다음과 같은 형태가 된다.

```text
상품번호 = 고정값
변경일시 >= 범위조건
```

---

# 2. 변경구분코드 조건의 위치

PK 컬럼 순서가 다음과 같기 때문이다.

```sql
상품번호 → 변경일시 → 변경구분코드
```

여기서 중요한 점은:

- 상품번호는 선두 컬럼이라 매우 잘 탐색 가능
- 변경일시는 두 번째 컬럼
- 변경구분코드는 세 번째 컬럼

따라서 변경일시에 범위 조건이 걸리는 순간:

```sql
변경일시 >= ...
```

그 뒤 컬럼인 변경구분코드는 인덱스 탐색 효율이 떨어질 수 있다.

즉 다음과 같은 상황을 생각해야 한다.

```sql
상품번호 = 'ZE367'
AND 변경일시 >= 최근1년
AND 변경구분코드 = 'C2'
```

이 경우 인덱스는:

1. 상품번호로 범위를 좁히고
2. 변경일시 범위를 탐색한 뒤
3. 그 안에서 변경구분코드를 추가 필터링

하는 형태가 될 가능성이 높다.

---

# 3. MAX() 사용 시 생각할 점

다음 형태는 흔히 등장한다.

```sql
SELECT MAX(변경일시)
```

하지만 MAX는 일반적으로:

- 조건에 맞는 후보를 찾고
- 그 중 최대값 계산

과정이 필요하다.

따라서 데이터 범위가 크면 비용이 커질 수 있다.

---

# 4. INDEX_DESC + ROWNUM 방식

다음 형태도 자주 등장한다.

```sql
INDEX_DESC
ROWNUM <= 1
```

이 방식은 보통:

```text
가장 최신 데이터부터 역순으로 읽다가
조건에 맞는 첫 건 발견 시 즉시 종료
```

전략이다.

즉:

- 전체 MAX 계산 없이
- 빠르게 한 건만 찾고 종료 가능

한 구조인지 생각해야 한다.

---

# 각 보기별로 생각해볼 포인트

## ①번

생각할 점:

```sql
서브쿼리에서 변경구분코드 = 'C2' 조건이 없음
```

즉:

- 최근 1년 내 최종 변경일시를 먼저 찾고
- 바깥에서 C2 여부를 확인

하는 구조다.

이 경우 정말 원하는 데이터가 맞는지 생각해봐야 한다.

---

## ②번

생각할 점:

```sql
서브쿼리 안에서도 변경구분코드 = 'C2'
```

즉:

- C2 데이터 중
- 최근 1년 내
- 가장 최신 변경일시

를 찾으려는 구조다.

다만 MAX 계산 비용도 함께 고려해야 한다.

---

## ③번

생각할 점:

```sql
단순 MAX(변경일시)
```

구조다.

가장 직관적이지만:

- 얼마나 많은 범위를 읽는가?
- 인덱스를 얼마나 효율적으로 사용하는가?

를 생각해야 한다.

---

## ④번

생각할 점:

```sql
INDEX_DESC
ROWNUM <= 1
```

즉:

- 최신 데이터부터 역순 탐색
- 조건 만족 시 즉시 종료

가능성이 있다.

여기서 핵심 질문은 이것이다.

```text
PK 인덱스 순서가
상품번호 → 변경일시 → 변경구분코드
일 때,

최신 변경일시부터 역순 탐색하면서
C2를 빠르게 찾을 수 있는가?
```

---

# SQLP 스타일 사고 방식

SQLP에서는 단순 문법보다 다음을 중요하게 본다.

- 인덱스 컬럼 순서
- 범위 조건 여부
- MAX 계산 비용
- 정렬 회피 가능 여부
- Stop Key 가능 여부
- 얼마나 빨리 탐색 종료 가능한가

즉 단순히:

```sql
조건이 많다 = 빠르다
```

가 아니라:

```text
인덱스를 어떤 방향으로 읽는가
언제 탐색을 멈출 수 있는가
```

를 보는 시험에 가깝다.
